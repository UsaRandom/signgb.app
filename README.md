# signgb.app

Browser companion for Game Boy cold wallets (DogeGB today; Solana, Pepecoin and Bellscoin coming soon). Scan the address QR from the Game Boy, build an unsigned transaction, type it into the Game Boy, scan the signed result, and broadcast. Your words and keys never leave the Game Boy.

Static site at https://signgb.app (gbsign.app redirects there).
